# Sam Batra Portfolio Website Plan

## Purpose

This portfolio should present Sam Batra as an early-career technology professional with three connected strengths:

- Technical support and troubleshooting
- Software development and web application work
- Security operations, leadership, and discipline from Marine Corps service

The website should feel professional, focused, and personal. It should show that you are learning HTML, CSS, and JavaScript, while also showing that you already have real-world experience in support, development, security, documentation, and leadership.

## Learning Goals

HTML:

- Use semantic elements like `header`, `nav`, `main`, `section`, and `footer`.
- Use classes to target specific pieces of content.
- Build a page structure before worrying about visual design.

CSS:

- Target elements and classes.
- Use color, spacing, typography, borders, and layout.
- Learn Flexbox or CSS Grid.
- Make the page responsive.

JavaScript:

- Select elements from the page.
- Listen for click events.
- Add and remove classes.
- Show, hide, or update content.

## Design Notes

Your strongest portfolio angle is not just "student developer." It is:

```text
Veteran + technical support + web development + security mindset
```

That combination should guide the design and content.

Avoid putting too much resume text on the screen at once. The website should summarize the resume, not copy the entire resume.

Use the Projects section to show technical work. Use the Career section to show credibility. Use the About Me section to show personality.

Make every section answer one question:

- Home: Who are you?
- Projects: What can you build?
- Career: What experience and education do you have?
- About Me: What kind of person and learner are you?
