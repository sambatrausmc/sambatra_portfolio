# Sam Batra Portfolio Project

This repository contains a static personal portfolio website for Sam Batra. It was built for a class project using HTML, CSS, and JavaScript, with separate pages for projects, career background, and an about section.

## Pages

- `index.html` - Home page and portfolio introduction
- `projects/index.html` - Project summaries and technical work
- `career/index.html` - Education, skills, and experience
- `about/index.html` - Personal background and professional story

## Technologies

- HTML5
- CSS3
- JavaScript

## How to View

Open `index.html` in a browser, or run a local static server from the project folder:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Project Goal

The goal of this project is to demonstrate front-end structure, responsive page design, clear navigation, and version-controlled development practices for a portfolio website.
